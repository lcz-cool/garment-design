# 设计稿页面结构

HTML 设计稿的章节顺序、每节该写什么、以及最容易写空的地方。整体目标：**一个没参与沟通的版师或供应商，只看这一页就能开始做事**。

**系列（一季多款）不走这一页**，系列页的章节与写法见 `references/series-mode.md`；单款页仍按本文件的章节写。

## 全局规则

- 章节是可增删的，不是固定模板。没内容的章节直接删，不要留空壳凑格式。
- 每节一个「判断」，不写「描述」。写「选 180 g 亚麻是因为要撑住 A 型下摆同时在盛夏不闷」，不写「面料为亚麻」。
- 数字必须给区间或精确值，不用「较多」「适中」。
- 中文为主，专业术语后附英文原文（方便对接供应商和搜索参考）。

## 00 · 页眉信息

款号 / 性别归属 + 品类 / 季节 / 设计日期 / 版本号。

款号用 `SS26-DR-001` 格式，类别栏写成 `男装 · 衬衫 Shirt` 这种「性别 + 品类」形式，让评审一眼知道在看哪条线。版本号从 `v1.0` 起，改动后递增。

**生产版还要有**：品名 / 系列 / 设计师 / 日期。系列填不出就写「单款」；设计师不知道就写「未指定」，**不要编名字**。缺这四项，改稿追溯到人就成了问题。

## 01 · 设计概念 Concept

**写什么**：一到两句主张 + 灵感来源 + 风格锚点。

**深度**：三行以内。概念是给人记住的，不是给人研究的。

**结构**：
- **语域（男装必写，女装不写）**：静奢 Quiet Luxury / 老钱 Old Money / Clean Fit，三选一。写在主张前面，因为全篇判断都要服从它。见 `menswear-register.md`
- 一句话主张（这件衣服解决什么问题 / 传达什么情绪）
- 灵感来源：具象的（一部电影、一种材质、一个场景），不要抽象的（「自然」「都市」）
- 风格锚点：两到三个坐标系，如「90 年代极简 × 日式解构」。**坐标系之间必须同向** —— 男装受语域约束只能有一个，女装可以叠两个，但「极简 × 巴洛克」这种互斥组合等于没锚点

**反例**：本设计以简约大方为核心理念，融合现代都市女性的审美需求……

## 02 · 款式结构 Construction

**单件写结构表，整套写构成表。** 这是两种不同的文档，不要混。

### 单件：结构表

**写什么**：从领口到下摆，按物理顺序逐项说明。

**必列**：廓形 / 衣长（落到身体位置）/ 领型 / 袖型与袖长 / 门襟 / 腰线 / 下摆 / 内部结构（里布、省道、支撑）

**深度**：分「视觉结构」和「内部结构」两层。视觉结构给客户看，内部结构给版师看。

### 整套：款式构成表

逐件列出，**每件一行**，四列：

| 件名 | 角色 | 结构要点 | 材质 |
|---|---|---|---|
| 酒红短款拉链夹克 | 主体（外层） | 翻领、前中拉链、双胸袋带盖、罗纹下摆袖口、短款 | 棉斜纹磨毛 320 g |
| 黑色高领打底 | 内搭 | 半高领、罗纹领口、合体修身 | 棉氨罗纹 220 g |
| 灰蓝工装阔腿裤 | 下装 | 高腰、多口袋、膝下微喇、水洗做旧 | 水洗斜纹棉 340 g |
| 白色皮手套 | 配饰 | 挂于腰间（造型项，不生产） | 羊皮 |
| 黑色厚底皮鞋 | 鞋履 | — | 牛皮 |

规则：

- **角色只有五种**：主体（外层）/ 内搭 / 下装 / 配饰 / 鞋履。主体只能有一个
- 配饰与鞋履不写生产参数，只写「造型项，不生产」或具体材质
- 结构要点只写决定版型的部分，细节工艺放 05 节
- 表后补一段「层次关系」：谁压谁、露出多少、腰线位置由谁决定

**层次关系是整套设计稿的价值所在**。单件都很好但叠起来垮掉，问题永远出在层次：外套长度盖住裤腰导致腿短、内搭领口高于外套领口导致杂乱、外层厚度吃掉了本来的廓形。

## 03 · 色彩方案 Colorway

**写什么**：主色 / 辅助色 / 点缀色，各给 **HEX + 色名 + 近似 Pantone TCX + 用在哪**。

**深度**：色卡 + 一句话说明为什么这个色属于这个季节。

**硬要求**：HEX 是屏幕色，供应商照它打不出色。每个色都要给近似 Pantone TCX 号，并在色板下方统一注明「**Pantone 为视觉近似，打色以实物色卡为准**」。给不出把握的编号就写「待色卡确认」，**不要编**一个看起来像的号。

**必须有**：至少主色要给出「同色系替代方案」—— 设计师改色时不用重新做一整套。

**生产版要有多套 Colorway**：主套用色卡块，另给 1–2 套完整替代配色（每套三色 + Pantone 近似），并用表格标注「替代套不动结构与面料，只换色」。只说「可换藏蓝」不算 Colorway。

## 04 · 面料与辅料 Material

**写什么**：主料 / 配料 / 里料 / 辅料（拉链、纽扣、衬布），各含成分、克重、手感、建议供应商类型。

**深度**：表格。每行一个材料，含「为什么选它」一列。

**关键**：克重必须与季节自洽 —— 春夏季出现 400 g 呢料是明显错误。

**生产版拆成两张表**：主料表（含为什么选它）+ **独立 BOM 表**。展示版把拉链纽扣线标塞进一行「辅料」，生产版必须逐类拆开，最少九行：主面料 / 里布 / 衬布 / 拉链 / 纽扣 / 缝纫线 / 织带松紧 / 标类 / 印花绣花。每行带规格与**色号**（Pantone TCX 或「待色卡确认」），不许只写「藏青」。字段清单见 `techpack.md`。

## 05 · 工艺要点 Make

**写什么**：三到五条会决定成败的工艺决策，不是全量工艺单。

**选什么写**：
- 影响廓形的（衬布选择、肩垫、压线位置）
- 容易做坏的（斜裁下摆、薄料开衩、弹力面料拼接）
- 影响成本的（手工部位、刺绣、特殊后整理）

**每条格式**：部位 → 做法 → 为什么这么做 → 风险提示

**生产版另加缝制规格表**（最少五行）：缝型（平缝 / 包缝四线三线 / 双针 / 来去缝）、针距 SPI、各部位缝份宽度、熨烫温度与是否需要垫布、特殊工艺参数（压褶 / 绗缝 / 洗水 / 三防 / 烫画）。

另加**图案与印花**子块：工艺方式（胶印 / 数码印 / 刺绣）、放置位置、定位尺寸、颜色数。**印花与绣花的矢量文件不在本节点交付**，必须写明「矢量另出」。

## 06 · 尺寸参考 Measurement

**写什么**：基准号型 + 关键部位尺寸表 + 松量说明。

**基准**：女装 `160/84A`（US 4 / EU 36）；男装 `170/88A`（US 38 / EU 48，对应 M）。男装尺码换算与 drop 值见 `menswear.md`。

**按品类走三条路径，不能混用。** 上装套裤装的部位表是这类文档最常见的错误。

| 路径 | 适用品类 | 必列部位 |
|---|---|---|
| **上装** | 衬衫、T 恤、Polo、针织、西装、外套、大衣、羽绒 | 领围、胸围、肩宽、衣长、袖长、下摆围 |
| **下装** | 长裤、西裤、半裙 | 腰围、臀围、裤长（裙长）、立裆、大腿围、裤口围（摆围） |
| **连衣裙** | 连衣裙、连身裤 | 胸围、腰围、臀围、衣长、肩宽、袖长 |

差异点必须守住：

- **领围**是男装衬衫的硬指标，女装几乎不用；男装衬衫不写领围，工厂没法打版
- **立裆 + 大腿围 + 裤口围**是裤装的硬指标，缺一项裤子就做不出来
- **臀围**对连衣裙和裤装必需，对衬衫和外套没有意义，不要硬凑
- 男装西装要写 **drop 值**，它比「修身」这类形容词更能让版师理解版型

**松量说明**：写清每个部位的松量值，这是版师唯一不能猜的东西。

**档差（放码）至少要提一句**：只给一个基准码，工厂没法出全码。写法不必给全码表，但必须说明「按 X cm/码放码」或列出关键部位的档差，例如「胸围 4 cm/码、衣长 1.5 cm/码」。没把握就写「档差待版型确认」，不要留空。

**unisex 要给两张表**：同一节里拆成「女装基准 160/84A」与「男装基准 170/88A」两张，各自成表，不许合并成一张取平均。

**必须标注**：这是设计目标尺寸，非成衣允差；允差按工厂标准另议。**平面图不承担标注与量取**，需要尺寸一律查本节。

**生产版另加两项**：

- **允差**：每个关键部位给 ± 值，如 胸围 ±1.0 cm、衣长 ±0.8 cm。缺允差，工厂按自己习惯做，一批货能差出两个码
- **测量方法**：写清起点与走向，如「后颈点沿背中线至下摆」「袖山顶点沿袖中线至袖口」。**没有测量方法的尺寸表等于没写** —— 同一条 102 cm，两种量法能差 2 cm

展示版可省略这两项，但一旦标了生产版就必须齐。

## 07 · 季节适配 Season Fit

**写什么**：三层论证 —— 物理层（克重、透气、里布）、场景层（通勤/度假/叠穿）、体验层（贴肤、活动度、抗皱）。

**反例**：适合春夏穿着，清爽舒适。

**正例**：180 g 亚麻斜纹，无里布，腋下加三角插片增加活动量；适合 22–30℃ 通勤与度假场景；贴肤偏干爽，久坐后自然褶皱是设计语言的一部分而非缺陷。

## 08 · 搭配建议 Styling

**写什么**：三个方向的上装/下装/鞋/配饰组合，每个方向一个场景（通勤 / 周末 / 场合）。

**深度**：两三行一个方向，不用展开。

## 09 · 生产提示 Production Notes

**写什么**：成本档位、最小起订量假设、主要风险点、可降本的替代方案。

**诚实原则**：不确定的写「待确认」，不编具体的工厂报价或检测报告编号。

## 10 · 设计假设 Assumptions

**写什么**：所有 AI 替设计师做决定的字段，逐条列出，标注「待确认」。

**为什么必须有这一节**：设计师需要知道哪些是他没说、被默认掉的。这一节直接决定他要不要返工。

格式：

```
性别归属：男装（描述未说明，按品类「牛津纺衬衫」推定）
目标人群：默认 25–35 岁都市男性（用户未指定）
视觉偏差：效果图渲染为拉链拉合，以 02 节构成表与平面图为准
```

**性别归属必须列在第一行**，它是全篇最基础的假设 —— 判错了，术语、版型、尺寸表全都跟着错。即使描述里说了性别，也照写一遍，标明「用户明确指定」。

**图片与文档的冲突必须单列一条**，写清「哪张图、偏在哪、以谁为准」。这条是交付质量的证据：说明你核过图，而不是把图直接塞进页面。

## 排版优先级

页面第一屏必须同时出现：**款号 + 名字 + 两张图**。评审时先看图，后看字。

**图片必须完整显示，不能裁切** —— 效果图用 `object-fit: contain` 而不是 cover。裁掉鞋或下摆，等于丢掉了比例判断的依据，尤其男装「裤长 + 鞋」是版型的一部分。宁可留白边，也不要裁。

章节编号用 01–10，小标题用大写字母间距拉开的英文标签（CONCEPT / CONSTRUCTION / COLORWAY），正文中文。这个中英混排是买手和供应商都认的格式。

**水印与底色**：生成图右下角带平台水印，去不掉。图片框与图注之间留出底部余量，或在图注里注明「图源水印为生成平台添加」。平面图若底色偏灰（不是纯白），不要硬塞进白框装作干净 —— 要么重出，要么在交付说明里写一句。

**给下游的格式**：HTML 是给人看的，工厂要的是文件。交付时提一句「可用浏览器打印另存为 PDF 发版师」，模板已带 A4 打印样式；需要 Excel 版尺寸表或 BOM 时再另外生成，不要在这一页里塞。**本页不充当完整 tech pack** —— 缝份、缝型、洗水标、成分标都还没写进去，别让下游误以为齐全。

## 打版交付：从位图到矢量

设计稿里的 `technical-flat.png` 是**沟通图**：它说明结构，但既不能量取、也不能放码。要做首版样衣，必须再走一遍矢量化。

### 一张能打的款式图必须有

| # | 项 | 缺了会怎样 |
|---|---|---|
| 1 | 前后片完整外轮廓（含分割位置） | 少一片就没法起样 |
| 2 | 关键部位尺寸标注（数值抄 06 节） | 在图上量取不可靠，标注才是依据 |
| 3 | 缝份说明（哪些边要加、加多少） | 默认 1 cm 不等于到处 1 cm |
| 4 | 纱向线 | 决定裤子会不会扭、条绒会不会反光 |
| 5 | 对称与对条对格标注 | 左右不一致是打版事故 |
| 6 | 工艺位置（袋位、扣位、开衩止点） | 位置差 1 cm，成品差一档 |

### 流程

1. 打开 `assets/flat-skeleton.svg`（A3 横版，图层已分好：底图 / 轮廓 / 结构线 / 标注 / 说明）
2. 把 PNG 放进 `layer-2-trace`，透明度压到 20%，锁定
3. 钢笔描外轮廓 → `layer-3`；领、袖窿、分割、袋盖等结构线用细虚线 → `layer-4`
4. 删掉底图图层，加尺寸标注 → `layer-5`（数值抄 06 节，不给估算）
5. 补纱向线、缝份说明、标题块
6. 导出 1:1 PDF（A3）

**刻意不做的事：自动描摹。** tracer 出来的曲线对版师没有意义，还会让下游误以为这就能打版了。描线是十分钟的手工活，比修一张错的自动结果便宜得多。

**放码**：矢量稿只是单码。全码按 06 节写的档差另做，这一页不承担推板。
