# 交付深度：展示版与生产版

同一份设计稿，两种深度。**展示版够提案，生产版才够打样。**

| | 展示版（默认） | 生产版 |
|---|---|---|
| 用途 | 参赛、作业、提案、内部评审 | 交工厂打样、小批量试产 |
| 判据 | 气质对、结构清、能讲清设计意图 | **字段齐不齐**，工厂能不能照着做 |
| 输出 | 效果图 + 款式图 + 10 节设计稿 | 同上，第 03–06 节加密，并补 BOM 与工艺规格 |
| 图形精度 | 沟通级 | 仍是沟通级 —— 见文末「两项不由 AI 生成」 |

**判据是「字段齐不齐」，不是「数值能否直接下单」。** 本 skill 能保证字段不缺、量法写清、色号可打；不能保证拉链长度配得上袋口深度这类只有版师能定的东西。这个边界必须写进设计稿，不许含糊。

## 行业八项与本 skill 的落点

| # | 行业项 | 落在哪 | 展示版 | 生产版 |
|---|---|---|---|---|
| 1 | 创意效果图 | `lookbook.png` + 01 节 | ✅ | ✅ |
| 2 | 平面款式图 | `technical-flat.png` + 02 节 | ⚠️ 正背面 | ⚠️ 正背面 + **缺详图声明** |
| 3 | 面料与辅料清单 BOM | 04 节 | 主料为主 | ✅ 独立 BOM 表 |
| 4 | 规格尺寸表 POM | 06 节 | 基础码 + 档差 | ✅ + 允差 + 测量方法 |
| 5 | 工艺制作说明 | 05 节 | 三条要点 | ✅ 缝制规格表 |
| 6 | 色彩方案 Colorway | 03 节 | 单套 | ✅ 主套 + 1–2 套替代 |
| 7 | 图案/印花/绣花文件 | 05 节子块 | 无 | ⚠️ 定位与工艺，**矢量另出** |
| 8 | 封面信息 | 页眉 + meta | 款号/季节/版本 | ✅ 补品名/系列/设计师/日期 |

## 生产版的字段要求

### 03 色彩 · 多 Colorway

主色板之外，至少再给一套**完整**替代配色。每套都要三色 + Pantone 近似，不能只说「可换藏蓝」。

写法：主套用色卡块，替代套用表格，标注「替代套不动结构与面料，只换色」。

### 04 面料 · 独立 BOM 表

展示版的一行「辅料」在生产版必须拆开。**最少九行**：

| 类别 | 必填字段 |
|---|---|
| 主面料 | 成分 / 克重 g/m² / 组织（斜纹、平纹、罗纹…）/ 后整理（磨毛、水洗、压光…） |
| 里布 | 成分 / 克重 / 用途范围（全里、半里、袖里） |
| 衬布 | 类型（无纺、有纺）/ 克重 / 用在哪个部位 |
| 拉链 | 号数 / 长度 / 齿型 / 颜色 / 位置 |
| 纽扣 | 规格（如 18L）/ 材质 / 数量 / 位置 |
| 缝纫线 | 材质（涤、涤棉）/ 规格（如 40/2）/ 配色规则 |
| 织带 / 松紧 | 宽度 / 材质 / 回弹要求 |
| 主标 / 洗水标 / 吊牌 | 材质 / 尺寸 / 车缝位置 |
| 印花 / 绣花 | 工艺方式 / 位置 / 尺寸（详见 05 节） |

每行都要带**色号**（Pantone TCX 或「待色卡确认」），不许只写「藏青」「米色」。

### 05 工艺 · 缝制规格表

展示版的三条「要点 + 风险」保留，另加一张规格表。**最少五行**：

| 项 | 写什么 |
|---|---|
| 缝型 | 平缝 / 包缝（四线、三线）/ 双针 / 来去缝 / 双折边 |
| 针距 SPI | 每英寸针数，如 12–14 SPI；三本针单独标 |
| 缝份 | 各部位缝份宽度，如 侧缝 1.0 cm、下摆 2.5 cm |
| 熨烫 | 温度区间、是否需垫布、中途定型点 |
| 特殊工艺 | 压褶 / 绗缝 / 洗水 / 三防 / 烫画，逐项写参数 |

另加**图案与印花**子块：工艺方式（胶印、数码印、刺绣）、放置位置、定位尺寸、颜色数。**矢量文件不在本节点交付**，写清「需另出」。

### 06 尺寸 · 允差与测量方法

| 项 | 要求 |
|---|---|
| 允差 | 每个关键部位给 ± 值，如 胸围 ±1.0、衣长 ±0.8 |
| 测量方法 | 写清起点与走向，如「后颈点沿背中线至下摆」「袖山顶点沿袖中线至袖口」 |
| 档差 | 保留现有相邻码差 |
| 基准 | 明确号型与对应国际码 |

**没有测量方法的尺寸表等于没写** —— 同一条 102 cm，两种量法能差 2 cm。

### 08 封面信息

页眉与 meta 区必须有：款号 / 品名 / 系列（可填「单款」）/ 季节 / 设计师 / 版本号 / 日期。

设计师一栏不知道就写「未指定」，不要编名字。

## 两项不由 AI 生成

### 局部放大详图（第 2 项）

口袋、门襟、领、拉链的局部大样，AI 画不准。画歪了比没有更糟 —— 工厂会照着做。

正确路径：把 `assets/flat-skeleton.svg` 交给版师手工描，按「描轮廓 → 删底图 → 抄 06 节尺寸 → 补纱向与缝份 → 导出 1:1 PDF」走。

生产版设计稿里**必须写明「局部详图待人工补充」**，不许默认读者知道。

### 图案/印花矢量文件（第 7 项）

印花、绣花要的是可无限放大的矢量 + 精确套色。AI 产出的是位图，工厂不能用。

生产版只交付「图案描述 + 定位尺寸 + 工艺方式 + 颜色数」，并注明**矢量需另出**。

## 生产版的验收标准

字段级，可自动检查：

1. BOM 表存在且 ≥9 行
2. 工艺规格表存在，且含缝型、SPI、缝份、熨烫四个关键词
3. 尺寸表含允差（±）与测量方法（起点 + 走向）
4. Colorway ≥2 套，每套括注 Pantone
5. 封面含品名、系列、设计师、日期
6. **明确写出「局部详图待人工补充」与「图案矢量另出」**

第 6 条是硬要求。少这一句，整份包会被当成可直接生产的 Tech Pack，而它并不是 —— 这种误解的代价比缺字段大得多。

跑 `python scripts/check_spec.py <目录> --production` 逐条核对。
