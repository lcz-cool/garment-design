# 男装高级感语域词库

判断标准，不是术语表。每条都配一个可执行门槛（数值 / 做法 / 可验证的画面），这样它能进设计稿，而不停留在形容词。

**什么时候读**：Step 3 定设计语言时（尤其选风格锚点、定色彩与克重），以及 Step 7 交付前自检。

> **词是英文时可直接进提示词**。`fitted with ease`、`one clean break, none at the back`、`drape, not boardy` 这类短语比中文形容词更能约束出图结果。

---

## 结论先行：「高级」不是一种语言，是三种语域，而且互相打架

| 语域 | 要什么 | 关键词 |
|---|---|---|
| **静奢 Quiet Luxury** | 挺括、笔直、利落 | 无需证明 |
| **老钱 Old Money** | 软糯、有张力、允许褶皱 | 我本如此 |
| **Clean Fit** | 刚刚好的整洁 | 我这样穿很舒服 |

同一件衣服不可能同时满足三种。**先选语域，再用词。**

最常见的失败不是审美差，是把三种语域混着用 —— 静奢的哑光克重 + 老钱的浅色拼色 + 先锋的细节密度，三套逻辑叠在一件衣服上，结果哪一种都没成立。词库本身救不了这个。

**选定时写进设计稿第 01 节**，格式：`语域：老钱（Old Money）—— 全篇只用这一套判断`。一个设计里出现第二个语域，就是在自我抵消。

## 01 廓形与比例

这一层决定「像不像正经衣服」，比面料更前置。数值按 170/88A 基准。

| 词 | English | 可执行标准 |
|---|---|---|
| 正肩 | shoulder seam on the bone | 肩缝落在肩骨端点，不内收不外延。落肩 ≤3 cm；超过就滑向 oversized，那是潮流语言不是高级语言 |
| 有余量的合身 | fitted with ease | 肩线精准但身不贴身。西装 +8~10、夹克 +12~16、大衣 +16~24 cm 胸围松量 |
| 成柱 | column proportion | 上身与下身宽度差不超过一档。上下都窄或上下都宽，都比「上宽下窄」高级 |
| 衣长到拇指第一关节 | hits the thumb knuckle | 外套盖住臀部、站直时下摆落在拇指第一关节附近。短于这个数就显局促 |
| 一处干净折 | one clean break, none at the back | 裤脚在鞋面只折一次，后片不堆。堆成水坑（puddle）会把视线往下拽 |
| 裤腿有余量 | trouser volume | 直筒 / 微锥 / 阔腿都成立，前提是裤脚与鞋有互动。窄裤脚 + 厚底鞋 = 比例断裂 |
| 自然腰 | natural waist rise | 裤腰落在肚脐附近。中腰是妥协，低腰是错误。前裆 26–28 cm（含腰头） |
| 三层以内 | max three layers | 内层 + 中层 + 外层。第四层开始臃肿，除非是功能性叠穿 |
| 露一截袖口 | a quarter inch of cuff | 外套袖口露出衬衫 0.6–1.2 cm，不多不少。这是「有内层」的唯一证据 |
| 宽度呼应 | width matching | 领带宽度 ≈ 驳领宽度（差 ±0.6 cm），领尖落在驳领中点。散件同理：袋盖宽 ≈ 腰带宽 |

## 02 肩与结构

高级感在结构上的核心是「少」—— 不是简单，是把结构藏起来。

| 词 | English | 可执行标准 |
|---|---|---|
| 软肩 | soft / natural shoulder | 无垫肩或 2–4 mm 薄垫，靠面料自身站住。那不勒斯体系的起点 |
| 无结构 | unstructured | 无胸衬、无硬衬，或只做半里。判断法：捏住前襟能整片塌下去 |
| 无肩缝 | seamless shoulder | 前后片与袖连裁。比软肩更进一步，但要求门幅 ≥150 cm，是成本项不是设计项 |
| 垂坠 | drape, not boardy | 拎起袖口，布应落成一道柔弧；支出来、像纸板就是 boardy |
| 藏在里面 | hidden construction | 压胶、嵌条、拉链都往内收。外观上的结构动作**一件只留一个** |
| 关节活量 | action back / gusset | 腋下或后背加活褶、三角插片。高级外套抬臂不拽，靠的是这个而不是弹力 |
| 褶皱是语言 | wrinkles as a language | 亚麻、水洗棉的自然褶不是缺陷，是材质证据。但只允许一种材质在皱 |

## 03 面料与手感

面料是廉价感最快的泄密处，也是最容易被「素色」掩盖的地方。**素不等于贵。**

| 词 | English | 可执行标准 |
|---|---|---|
| 克重 | cloth weight | 同品类里更重的几乎总是更贵相。衬衫 120–160、T 恤 180–220、西装 250–320、外套 340–500、大衣 500+ g/m² |
| 垂坠 | drape | 不粘身、不支棱、不堆。举袖看落弧，是这一项最快的验法 |
| 挺括 | holds shape | 静奢的核心。精纺 80S 以上，新品上身即笔直、裤中线如刀裁 |
| 软糯 | soft, lofty | 老钱的核心。低克重 + 疏松织法，穿旧了更好看。**与「挺括」互斥，不能都要** |
| 高捻 | high-twist | 抗皱、干爽、有细微沙响。夏天的西装与四季裤料首选 |
| 哑光 | matte / dull lustre | 不要 sheen。浅色一旦有亮面就立刻廉价，这是浅色单品的生死线 |
| 干爽手感 | dry hand | 不滑、不冰、不塑料。摸起来像纸或像洗过的棉，比丝滑更高级 |
| 面料记忆 | textile memory | 捏一把松开，不咬死褶。一捏一条印的料子洗两次就废 |
| 天然纤维 | natural fibre | 棉 ≥70%、羊毛 80%+、亚麻、真丝。纯聚酯只允许出现在外套面层 |
| 四步验料 | the four checks | 看洗标 → 摸回弹 → 捏死褶 → 撑开透光（能看清手指关节即不合格） |

**与 `season-fabric.md` 的关系**：季节档位给的是「这个季节能穿什么」，本表给的是「同品类里更贵相的那一档」。两者取交集，克重往高的那端靠。例：早秋外套季节区间 250–360，本表要求 340–500 → 取 340–360。

## 04 色彩

色彩的「高级」不是颜色本身，是**饱和度压住、明度差拉开、数量减到三个**。

| 词 | English | 可执行标准 |
|---|---|---|
| 低饱和 | chromatic restraint | 饱和度压在 ≤18%。灰调、雾面调、莫兰迪都在这一档 |
| 中性色系 | navy / charcoal / cream / camel / oatmeal | 藏蓝、炭灰、奶白、驼、燕麦。这是唯一不需要论证就能成立的色板 |
| 同色系深浅 | tone on tone | 两色明度差控制在 12–18（ΔL）。差太小看不出层次，差太大变拼色 |
| 三色上限 | three colours max | 含鞋与腰带。超过三个色，注意力就从人转到衣服上了 |
| 70 / 25 / 5 | dominant–support–accent | 主色 70%、同族辅助 25%、点缀 5%。点缀只允许一处 |
| 色彩深度 | colour depth | 日光下验色，不看店灯。真饱和的染会越洗越稳，发灰发粉的会掉 |
| 不抢戏 | the colour steps back | 衣服的颜色不该是别人记住你的第一个信息。紫色、正红、荧光都违反这一条 |
| 同族深色 | sibling darks | 要「有颜色」就在同一族里往深走（紫 → 深葡萄），而不是往饱和走 |

## 05 细节与五金

细节的作用是「近看才加分」，不是「远看很热闹」。

| 词 | English | 可执行标准 |
|---|---|---|
| 无标或极小 | no logo / sub-1cm | logo 宽度 ≤1 cm，或只做后腰内侧织标。**位置比大小更关键：能被人指出来的位置就已经太大了** |
| 真角扣 / 贝母扣 | horn / mother-of-pearl | 塑料扣一秒泄底。换扣成本 <10 元/件，回报最高的一道工序 |
| 金属统一 | matching metals | 皮带扣、表壳、五金同色系。银色配金色是明确的减分项 |
| 缝线密度 | stitch density | 8–10 针/英寸以上，远看看不出单根线。三本针只用于受力处 |
| 对条对格 | pattern matching | 条格在侧缝、袋盖处必须对齐。这是最贵的沉默信号 |
| 里布平整 | lining sits flat | 手伸进内里走一圈，不鼓包、不堆缝。里布起皱 = 赶工 |
| 口袋不鼓 | no bulging pockets | 袋布比主料薄一档。口袋里放手机不显轮廓，比加厚面料有效 |
| 按扣藏起来 | hidden snap | 外露按扣、装饰拉链、假袋盖都是「设计感」而非「高级感」 |
| 皮带收窄 | narrow belt | 宽度 ≤3 cm。两指宽的皮带是街头语域，不是这一套 |
| 干净收尾 | quiet finish | 袜子同色或隐形、鞋干净、无外露线头。这三件是零成本项 |

## 06 气质与状态词

这一层最虚，但它决定前五层怎么选。写设计稿时可直接当风格锚点。

| 词 | English | 含义 / 用法 |
|---|---|---|
| 克制 | restraint | 每件衣服只保留一个主张，其余删干净 |
| 做减法 | subtraction | 高级感不是加对东西，是删掉所有能被指认的东西 |
| 不表演 | not performative | 穿给场合，不穿给镜头。表演性单品 = 细节密度过高 |
| 被记住而非被注意到 | remembered, not noticed | 这一句是整套语域的总纲 |
| 利落有魂 | crisp with soul | 静奢。笔直、精确、收紧，靠密度而非厚度 |
| 松弛有骨 | ease with bone | 老钱。宽、软、允许使用痕迹，但肩与腰仍有支撑 |
| 刚刚好的整洁 | just-right neatness | Clean Fit。不追求贵，追求不出错。低饱和 + 合身 + 干净 |
| 刻意的随意 | sprezzatura | 算过的随意：袖子卷两折、扣子留一颗。算得太明显就失败 |
| 无需证明 | nothing to prove | 不靠 logo、不靠撞色、不靠廓形夸张来建立存在感 |
| 统一性 | consistency over novelty | 一季之内同一个签名反复出现，比每件都新更高级 |

## 07 反面词 · 廉价感触发器

**这张表比正面词表更好用** —— 设计时先扫一遍，命中两条以上就重做。

| 触发器 | 为什么 | 替代做法 |
|---|---|---|
| 大 logo / 满身字母 / 标语 | 把衣服变成广告牌 | ≤1 cm 刺绣，或只做内侧织标 |
| 大面积拼色 / 撞色超三处 | 注意力从人转移到衣服 | 同色系明度差 12–18 的「假拼色」 |
| 亮面化纤 / PU 皮 / 反光涂层 | 塑料光泽是最快的廉价信号 | 哑光高密尼龙、三层复合软壳 |
| 薄透 / 起球 / 一皱到底 | 洗两次就现形 | 克重上一个档，或换高捻 |
| 紧身小脚 / 超低胯 | 2010 年代遗产，已整体退场 | 直筒或微锥，腰在自然腰 |
| 过度 oversize（落肩 >3 cm） | 廓形喧宾夺主 | 落肩 ≤3 cm，身宽靠松量不靠落肩 |
| 裤脚堆成水坑 | 把视线往下拽，人显矮 | 一处干净折，或前短后长 |
| 外露按扣 / 装饰拉链 / 假袋盖 | 「设计感」冒充「高级感」 | 隐藏五金，结构只留一个动作 |
| 口袋鼓包 | 正面多两块凸起 | 袋布薄一档，袋口加深 |
| 金链外露 / 多层项链 / 腰包斜挎 | 配饰抢主体 | 一块素表，一条细链，二选一 |
| 两指宽皮带 + 大扣 | 街头语域混进来 | ≤3 cm，哑光针扣 |
| 黑皮鞋配白袜 / 厚底运动鞋配西裤 | 语域冲突，最典型的错配 | 袜子同色，鞋型与裤宽匹配 |

## 08 三套语域的配方对照（核心表）

同一组词，三种配比。开工前先在这张表里选一行，抄进设计稿第 01 节。

| 维度 | 静奢 Quiet Luxury | 老钱 Old Money | Clean Fit |
|---|---|---|---|
| **面料** | 高密、挺括、精纺 80S+、新品即笔直 | 低克重、疏松、软糯、天然光泽、允许旧 | 挺括 + 垂坠都要，中厚斜纹棉 |
| **剪裁** | 利落有魂：肩斜精确、裤中线如刀裁 | 松弛有骨：肩自然下垂、宽腿有余量 | 刚刚好的整洁：微宽松、不出错 |
| **色彩** | 低饱和莫兰迪：燕麦、雾咖、奶白 | 深重沉淀：藏蓝、墨绿、卡其、酒红 | 低饱和 + 一个情绪色点缀 |
| **细节** | 无标、五金哑光、几乎无装饰 | 格纹、粗花呢、乐福鞋、皮带 | 基础款、少 logo、鞋干净 |
| **关键词** | 无需证明 | 我本如此 | 我这样穿很舒服 |
| **容易翻车** | 做成「空白的贵」—— 素但没质感 | 全套穿上像在演戏 | 过于基础，滑向「像程序员」 |

## 10 反面案例（自检示范）

以下是按本表对一版失败设计的逐条核对，可直接当自检模板用：

| # | 问题 | 判定依据 | 正解 |
|---|---|---|---|
| 01 | **语域混用** | 静奢的哑光克重 + 老钱的浅色拼色 + 先锋的细节密度，三个逻辑互相抵消 | 选一行，其余全删 |
| 02 | **细节密度过高** | 悬浮门襟 + 双层拉链 + 压胶 + 立体袖克夫 + 弧形护颈，五个结构动作同时出现 | 一件只留一个动作 |
| 03 | **面积放大后饱和度失真** | 主色饱和度 22%、明度 33%，在锥形裤上勉强，放到阔腿大面积上读成「紫」而非「灰紫」 | 明度提到 45–50、饱和度压到 12–15 |
| 04 | **logo 位置** | 1.8 cm 已算克制，但放在立体袋下角是「能被指出来」的位置 | ≤1 cm，或移进后腰内侧织标 |
| 05 | **把「显腿长」当目标** | 局部拉长思路，会滑向精神小伙比例 | 改整体成柱：上下宽度差不超过一档 |
| 06 | **搭配写成造型师语气** | 「全米白同色系 + 银灰德比」不可执行 | 落到「宽裤 + 有分量的鞋 + 一处干净折」 |

## 边界

- **本表是男装语域**（静奢 / 老钱 / Clean Fit 是男装 discourse）。女装可借用 03 面料、04 色彩、05 五金的数值标准，但 08 的三分法不适用 —— 女装的判断轴是廓形与装饰度，不是这三个词。
- **三分法覆盖不到工装 / 机能 / 街头 / 先锋**。这些是另一条语域轴，硬套「静奢 / 老钱 / Clean Fit」只会做出四不像。遇到这类设计：01–07 的数值门槛（落肩 ≤3 cm、三色上限、针距、哑光、五金藏起来）照用，08 的配方对照跳过，语域写 `语域：工装（非三分法）`。
- 数值是设计目标与经验区间，**不是检测标准**；标注「互斥」的两项不可同时追求。
- 与本 skill 其他文件的冲突处理：**取更严的那一条**，并在设计稿 10 节标注取用依据。
